# ALADIN Stanford 15K feature store

ALADIN (nnU-Net ECG segmentation + reflection + logic diagnosis) run over 14,996
Stanford "after-2017" ECGs. This folder is a self-contained feature store; the raw
waveforms are **not** re-stored here (they live in the source npy / corpus).

## Files
```
features.parquet        one row per ecg_id: summary columns + `features_json`
arrays.lmdb/data.mdb     key = ecg_id (str) -> compressed npz of that record's arrays
aladin_store_tools.py    standalone access/query/plot helpers (this README's examples)
features/                (optional) append-only parquet shards from the run; features.parquet
                         is the consolidated version — either is readable.
```
Dependencies to use it: `numpy pandas pyarrow lmdb matplotlib` (the `aladin` package is
NOT required). Keep the `arrays.lmdb/` directory name intact.

## Quick start
```python
import aladin_store_tools as T
df  = T.read_features(".")                 # queryable summary table (14,996 rows)
rec = T.read_record(".", df.ecg_id[0])     # full nested dict for one record
T.plot_overview(".", rec_id, out="rec.png")           # store-only QC figure
T.plot_full(".", rec_id, npy=NPY, csv=CSV, out="f.png")  # 12-lead (needs source npy)
```

## features.parquet — summary columns (fast filtering, no LMDB needed)
| column | meaning |
|---|---|
| `ecg_id` | record key (GUID; joins to the source metadata CSV) |
| `bpm` | heart rate = 60·fs/median(hr) |
| `n_qrs`,`n_p`,`n_t` | beat/wave counts |
| `n_clusters`,`dominant_cluster_id` | # QRS morphology clusters; the dominant (normal) one |
| `n_abnormal_beats`,`n_early_beats` | abnormal-morphology / premature beat counts |
| `n_pvc_beats`,`n_pac_beats` | beats ALADIN labeled PVC / PAC |
| `n_diagnoses`,`diagnoses`,`subdiagnoses` | rhythm diagnoses (comma-joined names) |
| `features_json` | the full nested record metadata (arrays stripped) |

Example queries:
```python
T.find(".", pvc=True)                 # records with an ALADIN PVC beat (378)
T.find(".", diagnosis="AFIB")         # AFIB in main diagnoses
T.find(".", min_abnormal=1)           # >=1 abnormal beat (PVC-localization pool, 899)
```

## read_record(".", ecg_id) -> dict  (arrays from LMDB, scalars from parquet)
- `delineations.{p,qrs,t,abnormal_qrs,noise,afib}.{logits,uncertainty,binary_mask}` —
  each a length-N (=5000) array; ONE fused track per record (not per-lead). `binary_mask`
  is boolean (bit-packed on disk, auto-unpacked).
- `qrs` / `p` / `t` — lists of beats/waves. Each beat: `onset,offset,r` (sample idx @500Hz),
  `cluster_id`, `width`, `rr/rr_raw/rr_smooth`, `abnormal`, `isearly`, `diagnosis`
  (e.g. "PVC"/"PAC"/rhythm), `hr` (=RR in samples; bpm=60·fs/hr), `ecg` (extracted beat
  waveform), nested `p`/`t`, and `dominant_points` (see below).
- `qrs_clusters`/`p_clusters` — per-cluster templates (note: `template_ecg` may be empty in
  this run; use per-beat `ecg` grouped by `cluster_id` for morphology).
- `diagnosis`/`subdiagnosis` — {name, explanation, onset, offset}. Concatenated explanations
  = ALADIN's `get_full_explanation` text.
- NOT stored (reproducible from the input): raw 12-lead `ecg`, `ecg_normalized`.

## Dominant points (beat morphology "triangles")
Each beat/wave has `number_of_dominant_points` and `dominant_points` = curvature-based
vertices `[{j, support:[start,end]}, ...]`; `j` indexes into that beat's `ecg` window.
Connecting `(j, beat.ecg[j])` gives the piecewise-linear morphology ALADIN uses for
clustering — PVCs show a distinct vertex pattern vs normal beats.
NOTE: this store was written before dominant-point serialization was added, so
`dominant_points` here is `[]`; re-run/regenerate to populate it (the code now supports it).

## PVC dataset workflow (find → localize → chop → compare)
- **Find** (diagnosis of PVC): defer to the overread label — the source CSV `PVC` column
  (join by `ecg_id`). ALADIN's `n_pvc_beats` is a secondary signal.
- **Localize** the beat: fallback hierarchy — `diagnosis=="PVC"` → else `abnormal` beats →
  else non-`dominant_cluster_id` beats → else `isearly`/wide beats.
- **Chop**: slice the source 12-lead npy at the beat's `[onset:offset]` (any lead).
- **Compare morphology**: minority-cluster mean beat / PVC beat vs the dominant-cluster
  (normal) beat; and the dominant-point polyline. See `../aladin_test_outputs/pvc_examples/`.
- **Coverage audit**: overread-PVC records with `n_abnormal_beats==0 & n_clusters==1` have no
  ALADIN candidate to chop — surface these rather than silently dropping.
